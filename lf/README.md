# lf 配置

Go 写的终端文件管理器，ranger 的精神继承者，更快更轻。

## 文件说明

| 文件 | 用途 |
|------|------|
| `.config/lf/lfrc` | 主配置（显示/搜索/排序/快捷键/命令） |
| `.config/lf/pv.sh` | 预览脚本 |

## Bash 集成

```bash
lfcd() {
    local dir
    dir=$(command lf -print-last-dir "$@" 2>/dev/null) && cd "$dir"
}
alias l='lfcd'
```

- `l` — 退出时自动 cd 到所选目录
- `lf` — 原生命令，退出后留在原目录

## 界面布局

```
┌──────────┬────────────────────┬──────────────────────┐
│  目录树   │      文件列表       │       预览窗格        │
│  ratio 1 │      ratio 2       │       ratio 3        │
│          │                    │   md  → glow 渲染    │
│          │                    │   文本 → bat 高亮     │
│          │                    │   目录 → ls -lh      │
│          │                    │   二进制 → 类型+大小   │
└──────────┴────────────────────┴──────────────────────┘
```

## 快捷键

### 导航
| 键 | 功能 | 键 | 功能 |
|----|------|----|------|
| j/k | 上下 | gg/G | 顶部/底部 |
| h/l | 上级/打开 | . | 上级目录 |
| ~ / bs | 家目录 | | |

### 操作
| 键 | 功能 | 键 | 功能 |
|----|------|----|------|
| v | 反选 | y/d/p | 复制/剪切/粘贴 |
| zh | toggle 隐藏文件 | / | 搜索 |
| Enter | 系统默认打开 | O/e | nvim 打开 |
| Ctrl+N | 创建目录 | Ctrl+F | 创建文件 |
| R | 重命名 | q/Q | 退出 |

## 预览逻辑

```
文件 → file --mime-type
  ├─ text/*    → bat（高亮 + 行号，限 100 行）
  ├─ *.md      → glow -s dark
  ├─ 目录       → ls -lh（限 40 行）
  └─ 二进制     → 类型 + 大小（跳过内容）
```

## 设计原则

- SSH 友好 — 无 NERD Fonts 图标
- 零多媒体 — 不预览图片/音视频
- vim 键位 — 与编辑器一致
- 文本优先 — markdown 走 glow，其他走 bat
